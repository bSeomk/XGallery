# XGallery 1.0.0

X의 계정별 사진·동영상·GIF를 PC에 저장하고, 그룹·분류·좋아요로 정리해 보는 Windows용 로컬 갤러리입니다. Python이나 FFmpeg를 따로 설치하지 않고 사용할 수 있습니다.

XGallery는 X 및 콘텐츠 권리자와 제휴하거나 승인을 받은 공식 앱이 아닙니다. 사용 전 아래의 **이용 시 주의사항**을 확인하세요.

## 다운로드

[**Windows 64비트 실행 ZIP 다운로드**](https://github.com/bSeomk/XGallery/releases/download/v1.0.0/XGallery-1.0.0-win64.zip) · [1.0.0 릴리스](https://github.com/bSeomk/XGallery/releases/tag/v1.0.0) · [문제 제보](https://github.com/bSeomk/XGallery/issues)

일반 사용자는 **XGallery-1.0.0-win64.zip**만 받으면 됩니다. 소스·빌드 정보 ZIP은 프로그램 실행에 필요하지 않습니다. [최신 배포판](https://github.com/bSeomk/XGallery/releases/latest)은 같은 공개 저장소에서 확인할 수 있습니다.

## 주요 기능

- 계정과 서브 계정을 한 그룹으로 묶어 관리
- 사진·동영상·GIF를 선택해 수집하고, 기존 자료를 유지하며 새 게시물 업데이트
- 수집 작업 일시중지 및 저장된 목록에서 재개
- 대표 분류·계정·미디어 종류·해시태그 검색과 좋아요 필터
- 원본 사진 확대, 동영상 재생, 좌우 이동 및 전체화면 보기

## 실행 환경과 시작하기

- **Windows 10/11 64비트**
- 로그인 준비·수집·업데이트에 필요한 인터넷 연결
- 미디어를 저장할 충분한 디스크 공간
- **Microsoft Visual C++ v14 Redistributable x64**

1. 배포 ZIP을 다운로드하고, 쓰기 권한이 있는 **새 폴더에 전체 압축 해제**합니다.
2. 폴더 맨 위의 **XGallery.exe**를 실행합니다. EXE만 따로 옮기거나 `_internal` 안의 실행 파일을 직접 실행하지 마세요.
3. Microsoft Runtime 설치 안내가 표시되면 아래의 공식 설치 파일을 설치하거나 복구한 뒤 다시 실행합니다.

[Microsoft 공식 Runtime 설치 파일 · x64](https://aka.ms/vc14/vc_redist.x64.exe) · [Microsoft 설치 안내](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)

Runtime은 XGallery에 포함되어 있지 않습니다. XGallery가 이를 자동으로 설치하지 않으며, 설치는 사용자가 직접 진행합니다.

XGallery 자체는 별도 설치 과정 없이 실행합니다. 다만 설정과 로그인 정보 일부는 Windows 사용자별 앱 데이터 위치에 저장되므로, 프로그램 폴더 하나만 옮기는 완전한 Portable 방식은 아닙니다.

## 처음 사용하는 순서

### 1. 저장 위치 선택

**저장 위치 변경**에서 라이브러리를 보관할 폴더를 선택합니다. 기존 라이브러리가 있다면 그 폴더를 다시 선택해 사용할 수 있습니다.

### 2. X 로그인

**X 로그인**을 누르고 앱이 연 전용 Firefox 창에서 직접 로그인합니다. 로그인이 끝나면 전용 Firefox 창을 닫고 앱의 안내를 따라 완료합니다.

Firefox를 미리 설치할 필요는 없습니다. 최초 로그인 준비 시 Mozilla 공식 파일을 내려받아 디지털 서명을 확인하고 앱 전용 위치에 준비합니다. 처음에는 다운로드 때문에 시간이 걸릴 수 있습니다.

로그인 세션은 Windows 사용자 계정에 연결된 방식으로 암호화해 저장합니다. 다른 PC에서는 다시 로그인하세요. **로그인 세션 삭제**로 앱에 저장된 세션을 지울 수 있습니다.

### 3. 계정과 그룹 추가

**＋ 계정 / 그룹 추가**에서 프로필 주소 또는 `@아이디`를 입력합니다. 여러 계정은 줄을 바꾸어 입력하세요.

기존 그룹을 선택하거나 새 그룹 이름을 입력하면 됩니다. 같은 사람이 운영하는 여러 계정을 같은 그룹에 넣을 수 있습니다. 이미 등록된 계정은 입력한 그룹으로 이동하며 저장한 파일은 유지됩니다.

### 4. 미디어 수집

그룹 목록에서 원하는 그룹이나 계정을 선택한 뒤 **선택 그룹 수집**을 누릅니다. 그룹에 마우스를 올리면 오른쪽 메뉴에서 개별 계정을 고를 수 있습니다. 등록된 계정을 모두 확인하려면 **전체 계정 업데이트**를 사용합니다.

수집 창에서 **사진·동영상·GIF** 중 받을 종류와 수집 방법을 선택합니다.

| 수집 방법 | 사용할 때 |
| --- | --- |
| 새 게시물만 빠르게 업데이트 | 마지막 수집 이후 새로 올라온 자료를 확인할 때 |
| 전체 범위 확인 · 과거 누락 보완 | 과거 게시물 변경이나 저장하지 못한 자료를 다시 확인할 때 |

처음 선택한 계정의 미디어 유형은 빠른 업데이트를 선택해도 전체 범위를 한 번 확인합니다. 전체 범위 확인도 X에서 삭제되었거나 접근할 수 없는 자료까지 복구하지는 못합니다.

진행 상황은 아래의 **수집 상태 펼치기**에서 확인할 수 있습니다. 수집 중에는 **수집 일시중지**를 사용하고, 다음 실행에서 **미완료 작업 재개**로 이어갑니다. 재개 시 서버 응답이나 파일 상태에 따라 일부 파일은 다시 받을 수 있습니다.

## 갤러리 사용법

상단에서 그룹·계정·미디어 종류·분류를 선택하거나, 계정·해시태그·분류 이름을 검색할 수 있습니다. **페이지당** 값으로 한 화면에 표시할 개수를 조절합니다.

- **빈 별 → 노란 별:** 좋아요 등록
- **노란 별 → 빈 별:** 좋아요 해제
- **좋아요만:** 좋아요한 자료만 표시

미디어를 더블클릭하면 확대 뷰어가 열립니다. 현재 필터에 해당하는 자료를 페이지 경계와 관계없이 넘겨 볼 수 있습니다.

| 조작 | 동작 |
| --- | --- |
| `←` / `A` | 이전 미디어 |
| `→` / `D` | 다음 미디어 |
| 사진의 왼쪽 / 오른쪽 클릭 | 이전 / 다음 미디어 |
| `F` 또는 전체화면 버튼 | 전체화면 전환 |
| `Esc` | 전체화면 해제, 일반 보기에서는 뷰어 닫기 |

사진은 받은 원본 파일을 화면 크기에 맞춰 표시하며, 라이브러리 목록에서는 별도의 썸네일을 사용합니다. 동영상과 GIF는 뷰어의 재생 버튼으로 조작합니다.

### 분류와 태그

**분류 규칙**에서 해시태그와 대표 분류의 연결을 설정할 수 있습니다. 프로그램 옆의 `분류규칙.txt`로도 관리할 수 있습니다.

분류는 게시물의 태그와 사용자가 설정한 규칙을 바탕으로 정해집니다. 사진 내용을 AI로 분석하는 기능은 아닙니다. 뷰어의 **분류 변경**에서 수동 지정할 수 있으며, **미분류**도 직접 지정할 수 있습니다.

상단 분류 목록에는 현재 선택 범위에 해당하는 분류와 자료 개수가 표시됩니다. 개별 해시태그는 검색에 사용하고, 뷰어의 **태그 확인**에서 볼 수 있습니다. 태그가 없는 자료는 해당 버튼이 비활성화됩니다.

## 저장 위치와 백업

라이브러리 안에서 미디어는 계정별로 나뉘고, 사진·동영상·GIF는 각각 `images`·`videos`·`gifs` 폴더에 저장됩니다. 라이브러리에는 분류·좋아요·수집 기록과 썸네일도 함께 보관됩니다.

백업할 때는 **라이브러리 폴더 전체**와 프로그램 옆의 **분류규칙.txt**를 보관하세요. 앱을 종료한 상태에서 백업하는 것이 좋습니다. 파일만 개별적으로 옮기거나 이름을 바꾸면 갤러리의 기록과 실제 파일이 달라질 수 있습니다.

프로그램 폴더를 지워도 별도로 저장된 라이브러리와 Windows 사용자별 앱 데이터가 함께 삭제되는 것은 아닙니다. 로그인 정보와 개인 미디어가 든 폴더는 다른 사람에게 공유하지 마세요.

## 업데이트

**프로그램 업데이트**에서 새 버전을 확인하고 자동 확인·다운로드 옵션을 선택할 수 있습니다. 업데이트는 [공식 공개 저장소](https://github.com/bSeomk/XGallery)의 안정 릴리스를 사용합니다. 업데이트를 사용할 수 없다면 [최신 배포판](https://github.com/bSeomk/XGallery/releases/latest)을 직접 확인하세요.

업데이트는 파일 검증 후 앱 종료 상태에서 적용합니다. 적용 전 진행 중인 수집을 일시중지하고, 중요한 라이브러리와 분류 규칙을 백업하세요.

전체 배포본으로 수동 업데이트할 때는 새 폴더에 압축을 해제하고 기존 `분류규칙.txt`를 복사한 뒤, 앱에서 기존 라이브러리를 선택합니다. 특정 이전 버전용 업데이트 ZIP은 그 ZIP의 사용 안내를 따르세요.

## 문제가 생겼을 때

| 증상 | 확인할 내용 |
| --- | --- |
| 실행 시 Runtime 또는 DLL 오류 | Microsoft 공식 x64 Runtime을 설치·복구하고 배포 ZIP 전체를 압축 해제했는지 확인하세요. |
| 로그인 준비가 끝나지 않음 | 인터넷 연결과 보안 프로그램의 차단 여부를 확인하세요. |
| 인증·접근 오류 | X에서 해당 계정을 정상적으로 볼 수 있는지 확인하고 다시 로그인하세요. |
| DNS·네트워크 오류 | PC의 인터넷·DNS 연결 상태를 확인한 뒤 재개하세요. |
| X 조회 제한 | 잠시 기다린 뒤 다시 시도하세요. 반복 실행이 제한을 해제하지는 않습니다. |
| 저장 오류 | 디스크 여유 공간과 폴더 쓰기 권한, 다른 프로그램의 파일 사용 여부를 확인하세요. |
| 과거 자료가 갱신되지 않음 | 수집 방법에서 전체 범위 확인을 선택하세요. |

**도움말 / 라이선스 → 진단 로그 폴더 열기**에서 진단 로그를 확인할 수 있습니다. 진단 로그에는 오류 코드·진행 건수 등을 기록하며 로그인 정보·계정 아이디·URL·파일 경로는 기록하지 않도록 구성되어 있습니다.

문제를 제보할 때는 앱 버전, 오류 코드, 재현 순서를 알려주세요. 로그인 세션 파일·쿠키·개인 미디어는 첨부하지 마세요.

## 이용 시 주의사항

- XGallery는 X의 비공식 앱입니다. X 또는 콘텐츠 권리자의 승인이나 이용 허가를 제공하지 않습니다.
- [X 이용약관](https://x.com/en/tos)은 적용 법률에 따른 예외를 제외하고 X의 명시적 서면 허락 없는 스크래핑을 제한합니다. 사용 방식에 따라 조회·접근·계정 제한 또는 정지 등의 조치가 발생할 수 있습니다.
- 로그인 계정으로 정상적으로 접근 가능한 범위에서 동작합니다. 비공개 접근 제한이나 기술적 제한을 우회하는 기능은 제공하지 않습니다.
- X의 서비스 변경, 조회 제한, 삭제된 게시물, 접근 권한 등에 따라 수집이 실패하거나 일부 자료가 누락될 수 있습니다. 모든 자료의 수집이나 계정 안전을 보장하지 않습니다.
- 자료를 저장해도 저작권·초상권·개인정보 관련 권리는 이전되지 않습니다. 프로그램의 라이선스가 수집 자료의 재배포·판매·공개 권한을 제공하는 것은 아닙니다. 필요한 권한과 관련 법률·플랫폼 조건을 확인하세요.
